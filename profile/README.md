# 🌅 Sunset Studios

**Sunset — Minecraft: C# Edition**

Welcome to **Sunset Studios**, a solo-run development organization founded by a 15-year-old developer. I'm building ambitious Minecraft projects, starting with **Sunset: Minecraft: C# Edition** — a C# port of Minecraft: Java Edition.

Hey! I'm a 15-year-old developer passionate about Minecraft, C#, and building ambitious software projects.

## 🛠️ What I'm Building

- 🎮 **Minecraft: C# Edition** — Porting Minecraft: Java Edition to C#.
- 🖥️ **Sunset Launcher** — A polished desktop launcher for Sunset.
- 🧩 **Modding Support** — Exploring native C# mods and a custom modding API.
- ⚙️ **Server Development** — Working toward a C# server implementation.
- 💡 **Compatibility** — Aiming to reproduce Minecraft's gameplay and behavior as accurately as possible.
